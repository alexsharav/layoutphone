1. Игрок вводит ник
2. Создаётся комната
3. Этот игрок становится host
4. Host настраивает:
   - время придумывания темы
   - время верстки
   - количество игроков
5. Другие игроки заходят по ссылке
6. Host нажимает Start
7. Все пишут темы сайтов
8. Темы случайно распределяются между игроками
9. Начинается первый coding round
10. Игроки верстают сайт по теме
11. Следующий раунд:
    игрок получает уже не тему, а код предыдущего игрока
12. Он должен понять тему и продолжить/переделать сайт
13. Количество coding rounds = количество игроков
14. Показываются результаты:
    - исходная тема
    - все версии сайта по этой теме
15. Комната закрывается
